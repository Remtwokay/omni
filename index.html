ℹ️ About OMNI

• Search pulls real results from Wikipedia, OpenAlex, Crossref, and Openverse (CC-licensed images) — no key needed.
• Video results only appear if you add your own YouTube Data API key above.
• AI-written answers, Chat, and Vision (camera photos) need your own Claude API key.
• Downloads are only offered for openly-licensed media or direct file links — never bulk copyrighted content.
• Camera and Voice need this page served over https:// or localhost, not a plain double-clicked file.
• This isn't an autonomous agent — every action here is a direct response to something you typed, spoke, or captured.
